# StockLab 运行依赖（刻意保持精简，便于 NAS 上快速拉取与构建）
#
# 两个重要取舍：
#
# 1. 不依赖 pandas / TA-Lib
#    指标计算由 numpy 纯实现。群晖没有编译工具链，pip 装 TA-Lib 必然失败；
#    pandas 对本项目也没有必要，去掉能让镜像小很多、构建快很多。
#
# 2. 用 PyPI 的 tzdata 包提供时区数据库，而不是 apt 装 tzdata
#    这样 Dockerfile 里完全不需要 apt-get，构建只依赖 pip。
#    实测：清空系统时区搜索路径（PYTHONTZPATH=""）后，
#    zoneinfo.ZoneInfo("Asia/Shanghai") 与 APScheduler 仍工作正常。
#    在无法访问 Debian 源的网络环境里，这一条直接决定构建能否成功。

fastapi>=0.115,<1.0

numpy>=1.26

tzdata>=2024.1
